# Installation

### Requirements

- PHP >= 8.2
- CakePHP >= 5.3.6

### CakePHP Version Support

See the [version map](../README.md#compatibility).

### Installation via composer

First, require the package through Composer:

````
composer require orca-services/cakephp-app-version
````

Then load the plugin in your application with the plugin load command:

````
php bin/cake.php plugin load AppVersion
````

Alternatively, load it manually as documented in the section
[Loading a Plugin](https://book.cakephp.org/5.x/plugins.html#loading-a-plugin)
in the CakePHP CookBook.

### Installation alternatives

Refer to the CakePHP CookBook section
[Manually Installing a Plugin](https://book.cakephp.org/5.x/plugins.html#manually-installing-a-plugin).
